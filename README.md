A program that writes the funniest final text a dying phone sends at one percent battery — one message, 145 characters, in the phone's own voice: "1%. Last text ever. Delete my search history, tell my owner I loved them, and don't let the tablet speak at my funeral. It never liked me anyway."

## Run it

```sh
python3 main.py
```

Writes the text to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), self-checks it is 1–200 characters, and verifies the bytes by reading them back.
